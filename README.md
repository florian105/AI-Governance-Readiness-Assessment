## 📊 Overview

This interactive diagnostic helps B2B companies (€2M-€20M revenue) assess their revenue systems maturity across 4 key dimensions:

- **📊 Data & Systems** - Data unification and governance
- **🎯 Strategy & Alignment** - Cross-team strategic coherence
- **🤖 AI & Automation** - Technology maturity and responsible AI usage
- **⚡ Execution & Optimization** - Continuous improvement culture

## ✨ Features

- **20-question interactive assessment** with 1-5 scale responses
- **Real-time scoring** across 4 dimensions with visual radar chart
- **AI-powered personalized analysis** using Claude API
- **Email capture** with GDPR-compliant consent management
- **Automated data collection** to Airtable via Netlify Functions
- **Responsive design** built with Tailwind CSS and React

## 🛠️ Tech Stack

- **Frontend:** React (via Babel standalone), Tailwind CSS
- **Visualization:** Chart.js (radar chart)
- **AI Analysis:** Anthropic Claude API (claude-sonnet-4)
- **Backend:** Netlify Functions (serverless)
- **Database:** Airtable
- **Deployment:** Netlify

## 💡 How It Works

1. **User completes 20 questions** across 4 sections (5 questions each)
2. **System calculates scores** per section and total (0-100 scale)
3. **Email collection** with GDPR-compliant consent
4. **AI generates personalized analysis** using Claude API with detailed prompt engineering
5. **Results displayed** with radar chart, section breakdowns, and actionable recommendations
6. **Data stored** in Airtable for follow-up and analysis
